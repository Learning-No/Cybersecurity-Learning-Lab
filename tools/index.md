<article class="hub-card tool-entry" data-category="network" data-search="iproute2 ip linux interface local address routing table"><p class="tag">NETWORKING · LINUX</p><h2>iproute2 · <code>ip</code></h2><p>Inspect Linux interfaces, IP addresses, and routes. A good first stop for understanding local network configuration.</p><p><b>Start here</b></p><pre><code>ip address show
ip route show</code></pre><p><b>Use for:</b> local interface address and default route inspection.</p><a class="card-link" href="https://man7.org/linux/man-pages/man8/ip.8.html" target="_blank" rel="noopener">Official manual ↗</a></article>
<article class="hub-card tool-entry" data-category="network" data-search="dig bind dns records resolver lookup"><p class="tag">NETWORKING · DNS</p><h2>BIND utilities · <code>dig</code></h2><p>Query DNS records and inspect answer details, TTL, response flags, and resolver behavior.</p><pre><code>dig example.com A
dig example.com MX</code></pre><p><b>Use for:</b> learning name resolution and DNS record types.</p><a class="card-link" href="https://bind9.readthedocs.io/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="network" data-search="host dns lookup command line"><p class="tag">NETWORKING · DNS</p><h2><code>host</code></h2><p>A compact DNS lookup utility commonly distributed with BIND tools.</p><pre><code>host example.com
host -t AAAA example.com</code></pre><p><b>Use for:</b> quick record lookups and simple comparisons.</p><a class="card-link" href="https://bind9.readthedocs.io/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="network" data-search="curl open source http request response url"><p class="tag">NETWORKING · WEB</p><h2>curl</h2><p>Transfer data using URL-based protocols. Useful for understanding HTTP status, headers, and responses.</p><pre><code>curl -I https://example.com</code></pre><p><b>Use for:</b> ordinary requests to your own or explicitly authorized web apps.</p><a class="card-link" href="https://curl.se/docs/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="traffic" data-search="wireshark packet capture protocol analysis network"><p class="tag">TRAFFIC ANALYSIS</p><h2>Wireshark</h2><p>Inspect packet captures with a visual protocol dissector. Great for seeing DNS, TCP handshakes, and HTTP metadata.</p><p><b>First exercise:</b> inspect a sample capture or capture only your own lab traffic; identify DNS queries and TCP connection setup.</p><a class="card-link" href="https://www.wireshark.org/docs/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="traffic" data-search="tcpdump packet capture command line"><p class="tag">TRAFFIC ANALYSIS · CLI</p><h2>tcpdump</h2><p>A command-line packet analyzer for capturing and summarizing network traffic.</p><p><b>First exercise:</b> read the manual and use a small capture in an isolated lab. Packet captures may contain private information.</p><a class="card-link" href="https://www.tcpdump.org/manpages/tcpdump.1.html" target="_blank" rel="noopener">Manual ↗</a></article>
<article class="hub-card tool-entry" data-category="network" data-search="nmap network mapper service inventory authorized lab"><p class="tag">NETWORK INVENTORY</p><h2>Nmap</h2><p>Open-source utility for network discovery and service inventory. Results depend on network position, filters, and scan settings.</p><p><b>First exercise:</b> learn the output against your own local lab or an explicitly authorized training target. Never scan unknown public systems.</p><a class="card-link" href="https://nmap.org/book/man.html" target="_blank" rel="noopener">Official reference ↗</a></article>
<article class="hub-card tool-entry" data-category="web" data-search="owasp zap web application security scanner proxy open source"><p class="tag">WEB SECURITY</p><h2>OWASP ZAP</h2><p>An open-source web application security testing tool with a proxy and automated features.</p><p><b>First exercise:</b> use the ZAP getting-started tutorial with its deliberately vulnerable training target; keep active testing inside the lab.</p><a class="card-link" href="https://www.zaproxy.org/getting-started/" target="_blank" rel="noopener">Getting started ↗</a></article>
<article class="hub-card tool-entry" data-category="web" data-search="mitmproxy open source intercepting proxy http developer"><p class="tag">WEB DEBUGGING</p><h2>mitmproxy</h2><p>An interactive HTTPS-capable proxy useful for understanding requests and responses in a controlled environment.</p><p><b>First exercise:</b> follow the official tutorial with your own test application and dummy accounts.</p><a class="card-link" href="https://docs.mitmproxy.org/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="defense" data-search="osquery endpoint telemetry sql tables open source"><p class="tag">DEFENSIVE · ENDPOINT</p><h2>osquery</h2><p>Explore operating-system state using SQL-like queries, useful for learning inventory and endpoint investigation.</p><p><b>First exercise:</b> run read-only queries on your own test machine and document which table provides each result.</p><a class="card-link" href="https://osquery.io/" target="_blank" rel="noopener">Project site ↗</a></article>
<article class="hub-card tool-entry" data-category="defense" data-search="zeek network security monitor logs analysis open source"><p class="tag">DEFENSIVE · NETWORK</p><h2>Zeek</h2><p>A network security monitoring platform that turns observed traffic into structured logs for analysis.</p><p><b>First exercise:</b> inspect example logs and identify DNS, connection, and HTTP records before running a sensor.</p><a class="card-link" href="https://docs.zeek.org/" target="_blank" rel="noopener">Documentation ↗</a></article>
<article class="hub-card tool-entry" data-category="defense" data-search="suricata ids ips network threat detection open source"><p class="tag">DEFENSIVE · DETECTION</p><h2>Suricata</h2><p>An open-source network threat detection engine supporting IDS, IPS, and network security monitoring use cases.</p><p><b>First exercise:</b> read sample alert logs and learn rule concepts in an isolated lab before deploying sensors.</p><a class="card-link" href="https://docs.suricata.io/" target="_blank" rel="noopener">Documentation ↗</a></article>
