<article class="learning-page"><a class="back-link" href="{{ '/concepts/' | relative_url }}">← Concepts library</a><p class="eyebrow">CONCEPT 02 / NETWORKING</p><h1>Subnets & gateways: <em>organizing traffic</em></h1><p class="lead">A subnet defines a range of IP addresses that share a network prefix. A default gateway is the next-hop router a device uses to reach destinations outside its directly connected network.</p>
<div class="diagram-panel"><div class="network-map"><div class="network-cloud"><b>Network A · 192.168.10.0/24</b><div class="device-pair"><span>PC · 192.168.10.20</span><span>Laptop · 192.168.10.30</span></div><small>Same subnet: local delivery may occur directly</small></div><div class="flow-arrow">↕ gateway/router</div><div class="network-cloud"><b>Network B · 192.168.20.0/24</b><div class="device-pair"><span>Server · 192.168.20.10</span><span>Printer · 192.168.20.25</span></div><small>Different subnet: routing is needed</small></div></div><p class="diagram-caption">Illustrative private addresses only. A /24 IPv4 prefix represents 256 total addresses, with usable host counts depending on the subnet and special-purpose rules.</p></div>
<h2>Key terms</h2><div class="definition-list"><details><summary>Subnet mask / CIDR prefix</summary><p>Defines which address bits identify the network. For example, /24 corresponds to 255.255.255.0 in common IPv4 notation.</p></details><details><summary>Default gateway</summary><p>The router a host sends traffic to when no more-specific route matches. It is not necessarily the device that provides DNS.</p></details><details><summary>Routing table</summary><p>A set of destination prefixes and next-hop decisions that determine where packets should go.</p></details><details><summary>NAT</summary><p>Network Address Translation modifies address information as traffic crosses a device. It is common in home networks but is not the same thing as a firewall.</p></details></div>
<h2>Step-by-step packet path</h2><ol class="process-list"><li>Application resolves a destination name to an address if needed.</li><li>The operating system checks its routing table.</li><li>If the destination is local to the subnet, the host attempts direct local delivery.</li><li>If the destination is outside the subnet, the host sends the packet toward its configured gateway.</li><li>Routers forward the packet according to their routes until it reaches the destination network or is dropped.</li></ol>
<h2>Safe practice</h2><p>Use a diagram or your own local VM network. Compare the local address, prefix, and default route in read-only system settings. Do not change router routes or scan a shared network without permission.</p>
