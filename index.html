01 · Executive summary

What the program delivers

Fundamentals before tools, evidence before conclusions, and permission before everything.

Objective

Develop practical, defensible security skills grounded in networking, web technology, operating systems, identity, and risk, rather than a collection of tool commands.

Approach

Every weekly guide states a learning goal, a safe scope, a guided exercise, a deliverable, a self-check, and a completion checklist, all run in an isolated lab with fictional data.

Outcome

A sanitized assessment report, a remediation register, and an honest reflection: portfolio evidence that a learner can scope, test responsibly, rate risk, and communicate findings.
