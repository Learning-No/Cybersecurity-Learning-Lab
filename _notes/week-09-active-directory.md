## Week overview
Directory services organize identities and resources in many Windows environments. This week focuses on the concepts and defensive administration.

## Learning objectives
- Explain domains, domain controllers, organizational units, users, and groups.
- Describe centrally managed policy and why administrator accounts need special protection.
- Recognize common identity hygiene tasks.

## Concepts to learn
- **Domain:** an administrative boundary for identities and resources.
- **Domain controller:** a server that provides directory and authentication services.
- **Organizational unit:** a way to organize directory objects and apply policy.
- **Group policy:** centrally managed settings for systems and users.
- **Privileged account:** an identity with elevated access that needs extra controls and monitoring.
- **Identity lifecycle:** create, update, review, and disable accounts in a controlled way.

## Guided safe exercise
1. Draw a fictional company directory with two organizational units and several roles.
2. Create a table showing which role needs access to which fictional resource.
3. Mark administrator accounts separately and explain why they should not be used for everyday work.
4. Write a review checklist for old accounts, group membership, strong authentication, backups, and logging.
5. Use documentation or read-only views in an approved training lab.

## Deliverable
Submit a directory diagram, role-to-resource matrix, and five recommendations based on least privilege.

## Self-check
- What does a domain controller do?
- Why review group membership periodically?
- How does separating administrator accounts reduce risk?
