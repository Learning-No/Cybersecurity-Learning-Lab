## Learning objectives
- Identify the main parts of an HTTP request and response.
- Explain status codes, headers, cookies, and sessions.
- Inspect traffic to a site you own or an approved lab.

## Key concepts
- **Request:** method, path, headers, and optional body.
- **Response:** status code, headers, and optional body.
- **Cookie:** a small value the browser stores and sends back.
- **Session:** state used to associate requests with a user.
- **HTTPS:** HTTP protected by TLS in transit.

## Safe exercise
1. Open a local demo app or an approved training lab.
2. Use browser Developer Tools → Network to inspect a request and response.
3. Record the method, status code, and content type.
4. Never capture or share real credentials, session cookies, or private user data.

## Completion checklist
- [ ] I can describe an HTTP request and response.
- [ ] I know why session cookies must be treated as secrets.
- [ ] I can inspect traffic in a safe practice environment.
