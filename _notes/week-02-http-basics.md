## Learning objectives
- Identify the main parts of an HTTP request and response.
- Explain status codes, headers, cookies, and sessions.
- Use browser developer tools to inspect traffic to a site you own or an approved lab.

## Concepts to understand
- **Request:** method, path, headers, optional body.
- **Response:** status code, headers, and optional body.
- **Cookie:** a small value a server asks the browser to store and return.
- **Session:** server-side or token-based state used to associate requests with a user.
- **HTTPS:** HTTP protected by TLS in transit.

## Safe exercise
1. Open a local demo app or an approved training lab.
2. Use the browser Network panel to inspect one request and its response.
3. Record the method, status code, content type, and any relevant security headers.
4. Avoid capturing or sharing real credentials, session cookies, or private user data.
