## Learning objectives
- Explain IP addresses, subnets, ports, TCP, UDP, DNS, and HTTP at a beginner level.
- Set up a local virtual machine or use an approved guided training lab.
- Record lab scope, assumptions, and observations in a notebook.

## Concepts to understand
- **IP address:** identifies a network interface on an IP network.
- **Port:** a numbered endpoint used by a transport-layer service.
- **DNS:** maps domain names to records such as IP addresses.
- **HTTP/S:** protocols used by web clients and servers.

## Safe exercise
1. Draw a simple diagram of your own lab: host, virtual machine, and virtual network.
2. Inspect the network configuration of your own machine using its built-in system tools.
3. Write down the IP address ranges you control and the systems explicitly in scope.
4. If using a scanner, restrict it to a lab machine or a target that explicitly authorizes testing.
